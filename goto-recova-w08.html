Arquitetura do fluxo (nada aqui é reaberto — é isto que vamos construir)

Decisão D7 (pagamento simulado, esteira real) + D8 (idempotência) já fechadas. O desenho abaixo é o contrato entre as partes.

┌──────────┐  webhook assinado   ┌───────────────────┐   publish    ┌──────────┐  push (OIDC)  ┌─────────────────────┐
│ Shopify / │ ──────────────────▶ │ Cloud Run          │ ──────────▶ │ Pub/Sub   │ ────────────▶ │ Cloud Run            │
│ demo pay  │  HMAC-SHA256 ✓      │ /webhooks/orders/  │             │ order-    │               │ /internal/ledger/    │
└──────────┘  (raw body!)        │ paid               │             │ events    │               │ credit               │
                                  └───────────────────┘             └──────────┘               └──────────┬──────────┘
                                                                                                          │ create() fail-if-exists
                                                                                             Firestore ledger + summary increment (transaction)
                                                                                                          │
                                                                                          Dashboard Tela ⑥ lê summary (listener realtime)
  • Por que fila? webhook tem que ackar rápido (<1s) — processamento assíncrono com retry grátis do Pub/Sub
  • Por que create()? Firestore rejeita doc que já existe = idempotência de graça, sem transação no caminho crítico
  • Por que HMAC sobre raw body? JSON re-serializado quebra a assinatura — validar nos bytes exatos recebidos

1 · Middleware HMAC

src/webhooks/hmac.ts
import crypto from 'node:crypto';
export function verifyHmac(rawBody: string, header: string, secret: string): boolean {
  const digest = crypto.createHmac('sha256', secret).update(rawBody, 'utf8').digest('base64');
  const a = Buffer.from(digest), b = Buffer.from(header ?? '');
  return a.length === b.length && crypto.timingSafeEqual(a, b);  // timing-safe, sempre
}

⚠️ Ler o body como bytes crus (não usar middleware JSON antes da verificação). No Express: express.raw({type:'*/*'}) nesta rota.

✓ Aceito quando: teste unitário verde: (a) assinatura válida passa, (b) 1 byte alterado falha, (c) header ausente falha, (d) timing-safe (não vaza por comparação).
~1h

2 · Endpoint do webhook + publish

src/webhooks/orders-paid.ts
// POST /webhooks/orders/paid — ack rápido, processa assíncrono
app.post('/webhooks/orders/paid', express.raw({type:'*/*'}), async (req, res) => {
  if (!verifyHmac(req.body.toString('utf8'), req.header('x-recova-hmac')!, SECRET)) {
    span.addEvent('hmac.fail');                          // câmera liga
    return res.status(401).send('invalid signature');
  }
  const evt = extractOrderEvent(req.body);              // {order_id, session_id?, amount…}
  await topic.publishMessage({ json: evt });            // fila durável + retry grátis
  res.status(200).send('accepted');                    // ack < 1s — NÃO processa aqui
});
✓ Aceito quando: curl com assinatura válida → 200 + mensagem aparece no tópico; assinatura inválida → 401 e nada publicado.

3 · Subscriber: ledger idempotente + summary

src/ledger/credit.ts
// POST /internal/ledger/credit — push do Pub/Sub (auth OIDC da sub)
const ref = db.doc(`merchants/${mid}/ledger/${evt.order_id}`);
try {
  await ref.create({ ...evt, recovered: await wasRecovered(evt.session_id),
                     hmac_verified: true, attempts: 1, credited_at: FieldValue.serverTimestamp() });
  await incrementSummary(mid, evt.recovered);          // runTransaction com FieldValue.increment
} catch (e) {
  if (e.code === 6) {                                   // ALREADY_EXISTS → replay!
    await ref.update({ attempts: FieldValue.increment(1) });  // registra, NÃO credita 2×
    span.addEvent('ledger.replay_blocked');
  } else throw e;                                       // erro real → Pub/Sub reentrega
}
async function wasRecovered(sid?: string) {
  if (!sid) return false;                               // nunca adivinhar
  const s = await db.doc(`merchants/${mid}/sessions/${sid}`).get();
  return ['recovery_accepted','card_selected'].some(e => s.get('events')?.includes(e));
}
✓ Aceito quando: primeiro delivery credita; replay do MESMO order_id → attempts=2, receita NÃO sobe; erro simulado no summary → mensagem volta pra fila (retry).
